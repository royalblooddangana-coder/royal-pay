# Royal Pay starter

This is a starter preview for the Royal Pay reward app.

## Current status
- Royal Pay interface and withdrawal-method choices are included.
- The balance is demo-only.
- Real ads, reward crediting, and payouts are NOT connected.
- This project is a web preview, not an Android APK.

## Files
- `index.html` — app preview.

## Important before launch
1. Integrate the ad network SDK in a native Android project and follow the network's rewarded-ad policies.
2. Verify completed ad views on a trusted backend before crediting rewards.
3. Add a secure transaction ledger, anti-fraud checks, and an approved payout provider.
4. Test payment and privacy requirements before accepting real users.
